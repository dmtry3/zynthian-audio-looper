# Проверка этапа 0 на Zynthian V5

## 1. Установка

В WSL один раз:

```bash
cp scripts/deploy.env.example scripts/deploy.env   # вписать адрес Pi и пользователя
ssh-copy-id root@zynthian.local                    # чтобы не вводить пароль каждый раз
```

Дальше после каждого изменения:

```bash
./scripts/deploy.sh
```

Скрипт копирует исходники на Pi, собирает там (`scripts/install.sh`) и перезапускает Zynthian.
Если сборка падает с «g++: not found» или «rsync: not found», на Pi нужно `apt install g++ rsync`.
Проверка на Pi: `lv2info urn:audiolooper:looper` выводит описание плагина.

## 2. Плагин и виджет

1. Добавить **Audio Looper** в цепочку как аудиоэффект (категория Other).
2. Открыть плагин. Должен появиться виджет: полоса темпа сверху, большой прямоугольник,
   внизу TRACK и PART и ряд квадратиков кнопок.
   Прошлые плагины были MIDI-инструментами, для аудиоэффекта это проверяем впервые.
3. Звук проходит через плагин без изменений.
4. Страницы контроллеров: Record, Track, Navigate, Screens, Mix (подписи короткие).

Записать: появился ли виджет; если нет, что в `journalctl -u zynthian`.

## 3. Футсвитч через MIDI learn

1. Привязать кнопку футсвитча к контроллеру **Next Trk** (страница Track).
   В настройках привязки включить **momentary**.
2. Нажать и держать: квадратик T+ внизу светится, пока кнопка нажата. Отпустить: гаснет.
   Если квадратик загорается по одному нажатию и гаснет только по следующему,
   привязка работает как переключатель, тогда пробуем другие режимы привязки.
3. Короткий тап: TRACK +1, прямоугольник зелёный NEXT TRACK.
4. Удержание дольше 0,5 с: TRACK −1 (PREV TRACK) сразу на пороге, не дожидаясь отпускания.
5. То же для Undo (тап UNDO, удержание REDO) и Reset (удержание 1 с: RESET ALL).
6. Rec/Dub: прямоугольник становится красным сразу по нажатию.
7. Кнопки Loop и Mixer (страница Screens): надпись в углу меняется LOOP ↔ MIXER.

Записать: в каком режиме привязки работают тап и удержание.

## 4. Темп и сильная доля

1. Справа внизу источник темпа: `time:Position` (хорошо), `MIDI clock` (запасной путь) или `NO TEMPO`.
   `msgs` показывает, сколько сообщений time:Position пришло.
2. Поменять темп в Zynthian: BPM на виджете меняется, `msgs` растёт.
3. Запустить транспорт (метроном Zynthian): RUN, счёт «такт.доля» идёт,
   на сильной доле полоса вспыхивает, первая точка крупнее. Совпадает ли с метрономом на слух.
4. Остановить транспорт: STOP. Счёт продолжает идти по темпу (лупер считает сам).
5. Если источник `NO TEMPO`: включить в Zynthian отправку MIDI-клока на вход плагина,
   должно стать `MIDI clock` и `clk` с темпом.

Записать: источник темпа, совпадает ли сильная доля, меняется ли размер такта (число точек),
если поменять его в Zynthian.

## Приёмка этапа 0 (из ТЗ)

Кнопка футсвитча через MIDI learn меняет цвет заглушки, плагин видит темп и сильную долю Zynthian.
